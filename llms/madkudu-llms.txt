# MadKudu

> MadKudu is a predictive lead scoring and account intelligence platform for B2B sales and marketing teams. It scores fit, intent, and engagement signals to surface high-propensity accounts and people, and exposes this programmatically through the MadKudu API (MadAPI), a legacy Scoring API, and a hosted Model Context Protocol (MCP) server. MadKudu is now part of HG Insights (HG Sales Copilot).

Generated by the API Evangelist enrichment pipeline (method: generated) from apis.yml + repo artifacts. MadKudu publishes its own llms.txt at https://developers.madkudu.com/llms.txt.

## APIs
- [MadKudu API (MadAPI)](https://developers.madkudu.com/api): Account/person lookup, details, activities, enrichment, search, discovery, and organisation endpoints. Base URL https://madapi.madkudu.com. Auth: X-API-Key header.
- [MadKudu Legacy Scoring API](https://developers.madkudu.com/legacy-api): Fit / likelihood-to-buy / lead-grade scores. Base URL https://api.madkudu.com. Auth: HTTP Basic. 600 req/endpoint/min.

## MCP
- [MadKudu MCP server](https://developers.madkudu.com/mcp): Hosted MCP server at https://mcp.madkudu.com/YOUR_API_KEY/mcp (streamable HTTP) and /sse. 12 tools across account and person intelligence.
